Relative Motion

Now, let’s apply some of these vector properties to something more related to the real world. Let PPP be a particle in arbitrary motion. We define two reference frames, one inertial and one moving.

The position of PPP relative to the inertial frame is given by 𝒓\vector{r}r and relative to the moving frame is 𝒓rel\vector{r}_{\text{rel}}rrel​. The position of the origin OOO of the moving reference frame relative to the inertial frame is 𝒓O\vector{r}_OrO​. It then follows that the relationship between these vectors is:

𝒓=𝒓O+𝒓rel\vector{r} = \vector{r}_O + \vector{r}_{\text{rel}}r=rO​+rrel​
(466)

Taking the time derivative of 𝒓\vector{r}r gives the absolute velocity:

𝒗=𝒗O+𝛀×𝒓rel+𝒗rel\vector{v} = \vector{v}_O + \vector{\Omega}\cross\vector{r}_{\text{rel}} + \vector{v}_{\text{rel}}v=vO​+Ω×rrel​+vrel​
(467)

and taking the time derivative of 𝒗\vector{v}v gives the absolute acceleration:

𝒂=𝒂O+𝛀˙×𝒓rel+𝛀×(𝛀×𝒓rel)+2𝛀×𝒗rel\vector{a} = \vector{a}_O + \dot{\vector{\Omega}}\cross\vector{r}_{\text{rel}} + \vector{\Omega}\cross\left(\vector{\Omega}\cross\vector{r}_{\text{rel}}\right) + 2\vector{\Omega}\cross\vector{v}_{\text{rel}}a=aO​+Ω˙×rrel​+Ω×(Ω×rrel​)+2Ω×vrel​
(468)

The last cross-product term is known as the Coriolis acceleration.

Motion Relative to Earth Frames¶

The relative position vector of PPP to the center of the Earth is:

𝒓rel=(RE+z)𝒌^\vector{r}_{\text{rel}} = \left(R_E + z\right)\uvec{k}rrel​=(RE​+z)k^
(469)

Nonrotating Earth is a little weird... It means to assume that, for the purposes of these calculations, the Earth is not rotating. We’ll correct for the rotation in a minute.

where RER_ERE​ is the radius of the Earth (assumed constant for now) and zzz is the height of PPP above the surface of the Earth. The velocity of PPP relative to the nonrotating Earth is:

𝒗rel=z˙𝒌^+(RE+z)d𝒌^dt\vector{v}_{\text{rel}} = \dot{z}\uvec{k} + \left(R_E + z\right)\frac{d\uvec{k}}{dt}vrel​=z˙k^+(RE​+z)dtdk^​
(470)

Absolute Motion¶

The absolute velocity, in the ECI frame, is:

𝒗=𝒗C+𝛀×𝒓rel+𝒗rel\vector{v} = \vector{v}_C + \vector{\Omega}\cross\vector{r}_{\text{rel}} + \vector{v}_{\text{rel}}v=vC​+Ω×rrel​+vrel​
(477)

Geometrically, we find that 𝑲^=cos⁡ϕȷ^+sin⁡ϕ𝒌^\uvec{K} = \cos\phi\uvec{\jmath} + \sin\phi\uvec{k}K^=cosϕ^​+sinϕk^, which we can use to determine the angular velocity of the Earth:

𝛀=Ω𝑲^=Ωcos⁡ϕȷ^+Ωsin⁡ϕ𝒌^\vector{\Omega} = \Omega\uvec{K} = \Omega\cos\phi\uvec{\jmath} + \Omega\sin\phi\uvec{k}Ω=ΩK^=Ωcosϕ^​+Ωsinϕk^
(478)

In the ECI, 𝒗C=0\vector{v}_C = 0vC​=0, so we can find the absolute velocity of PPP:

𝒗=[x˙+Ω(RE+z)cos⁡ϕ]ı^+y˙ȷ^+z˙𝒌^\vector{v} = \left[\dot{x} + \Omega\left(R_E + z\right)\cos\phi\right]\uvec{\imath} + \dot{y}\uvec{\jmath} + \dot{z}\uvec{k}v=[x˙+Ω(RE​+z)cosϕ]^+y˙​^​+z˙k^
(479)

Next, the absolute acceleration of PPP is given by:

𝒂=𝒂C+𝛀˙×𝒓rel+𝛀×(𝛀×𝒓rel)+2𝛀×𝒗rel+𝒂rel\vector{a} = \vector{a}_C + \dot{\vector{\Omega}}\cross\vector{r}_{\text{rel}} + \vector{\Omega}\cross\left(\vector{\Omega}\cross\vector{r}_{\text{rel}}\right) + 2\vector{\Omega}\cross\vector{v}_{\text{rel}} + \vector{a}_{\text{rel}}a=aC​+Ω˙×rrel​+Ω×(Ω×rrel​)+2Ω×vrel​+arel​
(480)

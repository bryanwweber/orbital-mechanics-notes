Planetary Arrival: Capture Example

These examples apply the planetary arrival and capture equations to reentry at Earth and capture into orbit around Venus.

Reentry Corridor¶

To give an idea of the order of magnitude of the size of the reentry corridor, let’s take the example of an Earth return trajectory from Mars. By convention, spacecraft enter Earth’s atmosphere at the Kármán line, an imaginary line at an altitude of 100 km where the density of the atmosphere is significant. This gives rpr_prp​ values ranging from 6,378–6,478 km.

Next, let’s compute v∞v_{\infty}v∞​ for an arrival from Mars.

import math as m
mu = 1.32712E11  # km**3/s**2, Sun

r_i = 2.27939E8  # km, Mars
r_f = 1.49598E8  # km, Earth

v_f = m.sqrt(mu / r_f)  # km/s, Earth

a_t = (r_i + r_f) / 2  # km
E_t = - mu / (2 * a_t)  # km**2/s**2
v_t2 = m.sqrt(2 * (E_t + mu / r_f))  # km/s

Delta_vt = abs(v_f - v_t2)  # km/s

Here, vfv_fvf​ is the orbital velocity of Earth relative to the Sun, 29.785 km/s. vt,2v_{t,2}vt,2​ is the velocity of the spacecraft on the Hohmann transfer ellipse relative to the Sun, 32.729 km/s. This gives Δv=v∞=\Delta v = v_{\infty} =Δv=v∞​= 2.945 km/s.

Now, we can calculate the eccentricity, semimajor axis, and offset distance of the geocentric hyperbola given the two rpr_prp​ values at the surface of the Earth and at the Kármán line.

v_infty = Delta_vt

r_1 = 6378  # km
r_2 = 6478  # km
mu_f = 3.986E5  # km**3/s**2

e_1 = 1 + r_1 * v_infty**2 / mu_f
e_2 = 1 + r_2 * v_infty**2 / mu_f

a = mu_f / v_infty**2  # km

y_1 = a * m.sqrt(e_1**2 - 1)  # km
y_2 = a * m.sqrt(e_2**2 - 1)  # km
radius = y_2 - y_1

The offset distance to have rp=r_p =rp​= 6,378 km is y1=y_1 =y1​= 25041.1 km and to hit the edge of the atmosphere, y2=y_2 =y2​= 25249.5 km. This gives an annulus of thickness 208.4 km that the spacecraft must be within to arrive in Earth’s atmosphere. This is approximately the distance from Storrs, CT to the Statue of Liberty. If Earth was the size of a baseball, the reentry corridor would be about the thickness of a credit card.

Capture Orbit¶

Let’s continue the example of the Hohmann transfer from Neptune to Venus. At arrival at Venus, we want to enter a 300-km-altitude circular orbit to conduct atmospheric observations. What is the offset distance required to achieve this orbit? What is the required Δv\Delta vΔv?

To determine the Δv\Delta vΔv for the spacecraft, we first need to determine the parameters of the heliocentric transfer trajectory.

import math as m
mu = 1.32712E11  # km**3/s**2, Sun

r_i = 4.53239E9  # km, Neptune
r_f = 1.08209E8  # km, Venus

v_f = m.sqrt(mu / r_f)  # km/s, Venus

a_t = (r_i + r_f) / 2  # km
E_t = - mu / (2 * a_t)  # km**2/s**2
v_t2 = m.sqrt(2 * (E_t + mu / r_f))  # km/s

Delta_vt = abs(v_f - v_t2)  # km/s

Here, v_f is the heliocentric orbital velocity of Venus, and v_t2 is the spacecraft velocity on the heliocentric transfer orbit at Venus’s orbital radius relative to the Sun. Delta_vt is the change in velocity needed between Venus’s orbital velocity and the transfer orbit velocity. In other words, this is the spacecraft speed relative to Venus at the end of the heliocentric transfer orbit.

Delta_vt is equal to v∞v_{\infty}v∞​ that the spacecraft has at the SOI for the Venus-centered hyperbolic arrival trajectory. In addition, we know that the capture orbit altitude, and therefore the altitude of the hyperbolic periapsis, is 300 km. Using this we can find the periapsis radius and velocity.

v_infty = Delta_vt

r_Venus = 6051.8  # km
mu_f = 3.24859E5  # km**3/s**2

r_p = r_Venus + 300  # km

e = 1 + r_p * v_infty**2 / mu_f
a = mu_f / v_infty**2  # km

y = a * m.sqrt(e**2 - 1)  # km
h = y * v_infty  # km**2/s
v_p = h / r_p  # km/s

The eccentricity of the arrival hyperbola is e=e =e= 4.79143, the offset distance is 7850.34 km, and the speed at periapsis is vp=v_p =vp​= 17.210 km/s.

Next, we need to calculate the velocity on the circular capture orbit. Since the radius of the capture orbit is the same as the hyperbolic periapsis radius, calculating the speed can be done by Eq. 131. Then, we can calculate Δv\Delta vΔv.

v_p_capture = m.sqrt(mu_f / r_p)

Delta_v = abs(v_p - v_p_capture)

The velocity on the capture orbit is 7.15 km/s and the Δv\Delta vΔv is 10.06 km/s.

Minimum Capture Δv\Delta vΔv¶

Using Eq. 413 from the capture theory, we can compare the optimal apoapsis distances for arrivals at Venus.

For the example here, we can calculate the optimal rar_ara​:

r_a = 2 * mu_f / v_infty**2

The optimal apoapsis distance is 3350.61 km. This radius is inside the surface of Venus, so we cannot achieve the optimal Δv\Delta vΔv with these parameters.

Notice that the optimal rar_ara​ value is inversely proportional to the square of v∞v_{\infty}v∞​. Thus, a decrease in v∞v_{\infty}v∞​ will result in an increase in rar_ara​. For instance, transferring from Mars instead of Neptune, we find:

r_i_mars = 2.27939E8  # km, Mars

a_t_mars = (r_i_mars + r_f) / 2  # km
E_t_mars = - mu / (2 * a_t_mars)  # km**2/s**2
v_t2_mars = m.sqrt(2 * (E_t_mars + mu / r_f))  # km/s

Delta_vt_mars = abs(v_f - v_t2_mars)  # km/s
r_a_mars = 2 * mu_f / Delta_vt_mars**2

The v∞v_{\infty}v∞​ when transferring from Mars is 5.76 km/s, giving an optimal apoapsis radius of 19564.53 km. This is well outside Venus’s radius, so would be achievable by the spacecraft.

Classical Orbital Elements

We know that the solution to the 3-D vector orbit equation requires six independent elements to find a solution. So far, we have worked with r\vector{r}r and v\vector{v}v and their scalar components when determining orbits. In this section, we introduce the six classical orbital elements, which can also be used as a set of independent components of the orbit.

The six elements are also known as Keplerian orbital elements:

  1. aaa, the semi-major axis—a constant defining the size of the conic.

  2. eee, the eccentricity—a constant defining the shape of the conic.

  3. iii, the inclination—the constant angle between K^\uvec{K}K^ in the reference frame and h^\uvec{h}h^ in the orbital plane.

  4. Ω\OmegaΩ, right ascension (or longitude) of the ascending node—the right ascension of the point where the spacecraft crosses from below to above the fundamental plane of the reference frame. The crossing point is called the ascending node.

  5. ω\omegaω, argument of periapsis—the angular distance along the orbit from the ascending node to periapsis.

  6. TTT, time of periapsis passage—the time when the spacecraft passed periapsis.

Each of these six elements will be developed in the following subsections. This choice of six elements is not unique and equivalent parameters will be discussed below as well.

aaa, the Semi-Major Axis¶

The semi-major axis determines the size of the conic section. For a circle, it is the radius, while for an ellipse, it describes the width of the ellipse. For a hyperbola, the semi-major axis describes the distance from the origin of the Cartesian coordinate system.

The semi-latus rectum may specified instead of the semi-major axis, since with aaa and eee, ppp can be calculated. This is convenient for parabolic trajectories where the semi-major axis is not as meaningful.

Finally, the specific angular momentum, hhh, can also be used in place of the semi-major axis.

eee, the Eccentricity¶

The eccentricity describes the deviation of the trajectory from a circle. When e=0e=0e=0, the orbit is circular; for values of e<1e < 1e<1, the orbit is elliptical. When e=1e = 1e=1, the trajectory is parabolic and for e>1e > 1e>1, the trajectory is hyperbolic.

iii, the Inclination¶

The inclination is the angle from the K^\uvec{K}K^ axis in the reference frame to the angular momentum vector, h\vector{h}h, as shown in Fig. 46. The inclination ranges from 0° to 180°.

An inclination of 0° is an equatorial orbit. Orbits with inclinations from 0° to 90° are called prograde orbits because they rotate counterclockwise when viewed from above the north pole. This is the same direction as the surface of the Earth rotates and the same direction that planets orbit around the Sun.

An orbit with an inclination of 90° is called a polar orbit because it passes directly over the north and south poles of the primary object.

Orbits from 90° to 180° are called retrograde orbits because they rotate clockwise when viewed from above the north pole. This is the opposite direction of the surface of the Earth or the planets.

Ω\OmegaΩ, the Right Ascension of the Ascending Node¶

Consider an orbit inclined at angle iii to the reference plane of the coordinate system, as shown in Fig. 47. The spacecraft spends part of its time above the reference plane and part of the time below the reference plane.

The intersection of these two planes is a line, called the node line. This line will appear in calculations later. Since the orbit follows the perimeter of th orbital plane, this implies there are two crossing points:

  1. The descending node: The point when the spacecraft goes from above to below the reference plane

  2. The ascending node: The point when the spacecraft goes from below to above the reference plane

The right ascension of the ascending node is defined as the right ascension of the point where the spacecraft goes from below the reference plane to above it. This is therefore also the angle from the I^\uvec{I}I^ axis to the crossing point of the orbit.

The right ascension of the ascending node (abbreviated RAAN) can range from 0° to 360°, inclusive.

If the orbit has an inclination of 0° or 180°, the right ascension of the ascending node is not defined. For these inclinations the orbit is coplanar with the reference plane and does not go above or below it.

ω\omegaω, the Argument of Periapsis¶

In the perifocal reference frame, periapsis occurs at a true anomaly of 0°. The argument of periapsis determines how far around the orbit you have to go, starting at the ascending node, before you get to periapsis. This definition is shown in Fig. 48.

Alternatively, the right ascension of periapsis (abbreviated RAP or Π\PiΠ) may be specified. In this case, the angle given is the sum of the right ascension of the ascending node and the argument of periapsis:

If there is no periapsis, as in a circular orbit, then Π\PiΠ and ω\omegaω are both undefined.

TTT, the Time At Periapsis¶

The time since periapsis gives the location of the spacecraft on the orbit at some known time, t0t_0t0​. This can be specified in a number of ways. The time at periapsis, TTT, is simply the time when the spacecraft crossed periapsis. If this is known, along with the other orbital parameters and the current time, the current position of the spacecraft on the orbit can be determined.

Equivalently, the true anomaly at the epoch can be specified. The epoch is simply some known time; it is often conveniently chosen to be zero but this may not always be the case when using observational data. The true anomaly at this time can then be used as the sixth orbital element.

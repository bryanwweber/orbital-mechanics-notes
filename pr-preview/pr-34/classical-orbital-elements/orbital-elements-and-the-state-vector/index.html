Classical Orbital Elements and the State Vector

As we saw in the last section, we can replace the six elements in the state vector with six orbital elements which describe the orbit. If the position and velocity vectors are known, we need to be able to convert them to the classical orbital elements. Likewise, if we have six independent orbital elements, we might want to convert them into a state vector.

State Vector → Orbital Elements¶

Let’s assume that we are given the state vector, composed of r\vector{r}r and v\vector{v}v at some time t0t_0t0​. We would like to determine the six classical orbital elements:

  1. hhh

  2. eee

  3. iii

  4. Ω\OmegaΩ

  5. ω\omegaω

  6. ν\nuν

As we discussed previously, this set of six elements is not unique; for instance, the orbital angular momentum hhh can be replaced by the semi-major axis distance, aaa. Nonetheless, this set of six is a convenient set to calculate and other elements can be determined from this set.

Step 1—Position and Velocity Magnitudes¶

The first step in the conversion is to calculate rrr, vvv, vrv_rvr​, and v⊥v_{\perp}v⊥​. Recall that the radial velocity is the projection of the velocity vector onto the unit radial vector:

vr=v⋅rrv_r = \vector{v} \cdot \frac{\vector{r}}{r}vr​=v⋅rr​
(182)

and we can subsequently find the azimuthal velocity by the Pythagorean theorem:

v⊥=v2−vr2v_{\perp} = \sqrt{v^2 - v_r^2}v⊥​=v2−vr2​​
(183)

Step 3—Inclination¶

Once the angular momentum is calculated, we can calculate the inclination, iii. Let’s form a right triangle with one leg as the ZZZ component of the angular momentum and the hypotenuse as the magnitude of the angular momentum. Then the inclination is the angle adjacent to hZh_ZhZ​ and can be found by the inverse cosine, as shown in Eq. 184.

i=cos⁡−1(hZh)i = \cos^{-1}\left(\frac{h_Z}{h}\right)i=cos−1(hhZ​​)
(184)

Since the inclination is restricted to lie between 0° and 180°, we do not need to worry about the quadrant ambiguity inherent in the inverse cosine function.

The inclination of this orbit is i=i =i= 124.05°. We know for retrograde orbits, the inclination must be between 90° and 180°, which is the case here. The inclination is the second orbital element.

Step 4—Right Ascension of the Ascending Node¶

Next, we will calculate the right ascension of the ascending node. The ascending node is the point on the line of nodes where the spacecraft ascends above the reference plane. Since the line of nodes is defined by the intersection of the orbital plane and the reference plane, it must lie in both planes.

Therefore, the node line is perpendicular to the normal vectors of both the reference plane and the orbital plane. We can find the perpendicular vector by taking the cross product of a vector normal to the reference plane and a vector normal to the orbital plane. For convenience, we choose the K^\uvec{K}K^ vector and the h\vector{h}h vector, as shown in Eq. 185.

N=K^×h\vector{N} = \uvec{K}\cross\vector{h}N=K^×h
(185)

Then, similar to the inclination, we form a right triangle where the XXX component of N\vector{N}N is one leg and the magnitude of N\vector{N}N is the hypotenuse. The right ascension of the ascending node is the angle adjacent to NXN_XNX​ so it can be found by the inverse cosine, as shown in Eq. 186.

Ω=cos⁡−1(NXN)\Omega = \cos^{-1}\left(\frac{N_X}{N}\right)Ω=cos−1(NNX​​)
(186)

However, unlike the inclination, Ω\OmegaΩ can vary from 0° to 360°, so we need to determine the appropriate quadrant for the resulting angle. We can do this by comparing the sign of the YYY component of N\vector{N}N.

If NY≥0N_Y \geq 0NY​≥0, then N\vector{N}N must be pointing to the first or second quadrant and 0° ≤ Ω\OmegaΩ ≤ 180°. If NY<0N_Y < 0NY​<0, then N\vector{N}N must be pointing to the third or fourth quadrant, so 180° < Ω\OmegaΩ < 360°. We can express this fully with the conditions in Eq. 187.

Ω={cos⁡−1(NXN)NY≥02π−cos⁡−1(NXN)NY<0\Omega = \begin{cases} \cos^{-1}\left(\frac{N_X}{N}\right) & N_Y \geq 0 \\ 2\pi - \cos^{-1}\left(\frac{N_X}{N}\right) & N_Y < 0 \end{cases}Ω={cos−1(NNX​​)2π−cos−1(NNX​​)​NY​≥0NY​<0​
(187)

Step 5—Eccentricity¶

The fourth orbital element is the eccentricity. Way back in Eq. 122, we found the eccentricity vector as the constant of integration of the equation of motion. Repeating the equation here:

e=r˙×hμ−rr\vector{e} = \frac{\dot{\vector{r}}\cross\vector{h}}{\mu} - \frac{\vector{r}}{r}e=μr˙×h​−rr​

If you’re using a computer to do calculations, this form is the simplest to use. However, we can replace the cross product and simplify Eq. 122 somewhat.

e=1μ[(v2−μr)r−rvrv]\vector{e} = \frac{1}{\mu}\left[\left(v^2 - \frac{\mu}{r}\right)\vector{r} - r v_r \vector{v}\right]e=μ1​[(v2−rμ​)r−rvr​v]
(188)

Eq. 188 is useful if you’re doing calculations out by hand, since you don’t have to do any cross products, only scalar multiplications of the vectors.

The magnitude of the eccentricity can be found in the usual method programmatically, or with a form simplified from Eq. 188, as shown in Eq. 189.

e=1+h2μ2(v2−2μr)e = \sqrt{1 + \frac{h^2}{\mu^2}\left(v^2 - \frac{2\mu}{r}\right)}e=1+μ2h2​(v2−r2μ​)​
(189)

Again, Eq. 189 is useful for hand calculations.

Step 6—Argument of Periapsis¶

The last two orbital elements are found using the algebraic definition of the dot product, Eq. 190.

A⋅B=ABcos⁡θ\vector{A}\cdot\vector{B} = A B \cos\thetaA⋅B=ABcosθ
(190)

where A\vector{A}A and B\vector{B}B are arbitrary vectors, AAA and BBB are their magnitudes, and θ\thetaθ is the angle between the vectors.

By definition, the eccentricity vector points towards periapsis. Moreover, the argument of periapsis is the angle from the ascending node to periapsis following around the orbit. In other words, the argument of periapsis is the angle between the eccentricity vector e\vector{e}e and the node line N\vector{N}N. We can solve for ω\omegaω by using Eq. 190.

ω=cos⁡−1(e⋅NeN)\omega = \cos^{-1}\left(\frac{\vector{e}\cdot\vector{N}}{e N}\right)ω=cos−1(eNe⋅N​)
(191)

Like the right ascension of the ascending node, the argument of periapsis can vary from 0° to 360°. To determine the appropriate quadrant, we can inspect the sign of the ZZZ component of e\vector{e}e.

If eZ≥0e_Z \geq 0eZ​≥0, then e\vector{e}e points up and periapsis must be between the ascending node and descending node, so 0° ≤ ω\omegaω ≤ 180°. On the other hand, if eZ<0e_Z < 0eZ​<0, then periapsis must be between the descending and ascending nodes, and 180° < ω\omegaω < 360°. We can express this fully with the conditions in Eq. 192.

ω={cos⁡−1(e⋅NeN))eZ≥02π−cos⁡−1(e⋅NeN))eZ<0\omega = \begin{cases} \cos^{-1}\left(\frac{\vector{e}\cdot\vector{N}}{e N}\right)) & e_Z \geq 0 \\ 2\pi - \cos^{-1}\left(\frac{\vector{e}\cdot\vector{N}}{e N}\right)) & e_Z < 0 \end{cases}ω={cos−1(eNe⋅N​))2π−cos−1(eNe⋅N​))​eZ​≥0eZ​<0​

Step 7—True Anomaly¶

The final orbital element is the true anomaly, ν\nuν. The true anomaly is the angle from the apse line to the position vector. In other words, it is the angle between e\vector{e}e and r\vector{r}r. We can solve for ν\nuν by using Eq. 190.

ν=cos⁡−1(e⋅rer)\nu = \cos^{-1}\left(\frac{\vector{e}\cdot\vector{r}}{e r}\right)ν=cos−1(ere⋅r​)
(193)

Like the right ascension of the ascending node, the true anomaly can vary from 0° to 360°. To determine the appropriate quadrant, we can inspect the sign of the radial component of the velocity, vrv_rvr​.

If vr≥0v_r \geq 0vr​≥0, then r\vector{r}r is increasing in length and the spacecraft must be flying away from periapsis, so 0° ≤ ν\nuν < 180°. On the other hand, if vr<0v_r < 0vr​<0, then r\vector{r}r must be getting shorter and the spacecraft must be flying towards periapsis, such that 180° ≤ ν\nuν < 360°. We can express this fully with the conditions in Eq. 194.

Orbital Elements → State Vector¶

The algorithm to convert from the orbital elements back to the state vector is somewhat more involved, so we do not include the complete derivation here. There are two steps in this algorithm:

  1. Use the orbital elements eee, ν\nuν, and hhh to represent r\vector{r}r and v\vector{v}v in the perifocal frame

  2. Rotate the perifocal frame so that the axes align with the inertial axes using the orbital elements Ω\OmegaΩ, ω\omegaω, and iii.

The first step is rather simple, but the derivation of the second step requires a long digression on the topic of coordinate transformations. So, we’ll skip the derivation and get right to the point.

Step 1—Transform to Perifocal Frame¶

Remember that the perifocal frame is defined in the orbital plane with the unit vectors p^\uvec{p}p^​, q^\uvec{q}q^​, and w^\uvec{w}w^, as shown in Fig. 42. The position and velocity components in the perifocal frame are given by Eq. 177 and Eq. 180, respectively.

Python

v_w = mu / h * np.array((-np.sin(nu), e + np.cos(nu), 0))

For this example, we find rω=\vector{r}_{\omega} =rω​= -8117.7120 p^\uvec{p}p^​ + 3017.0767 q^\uvec{q}q^​ km and vω=\vector{v}_{\omega} =vω​= -7.0680 p^\uvec{p}p^​ + 0.2067 q^\uvec{q}q^​ km/s.

Step 2—Rotate the Perifocal Frame¶

The second step of this algorithm is to apply the set of coordinate transformations that converts the perifocal frame into the inertial frame. It turns out that a set of three rotations applied sequentially will accomplish this goal. These steps are shown in Fig. 50.

  1. Rotate around the w^\uvec{w}w^ axis until the p^\uvec{p}p^​ axis is aligned with the node line

  2. Rotate around the node line until the w^\uvec{w}w^ axis is aligned with the ZZZ axis

  3. Rotate around the ZZZ axis until the p^\uvec{p}p^​ axis is aligned with the XXX axis

Step 2.1—Rotate Until p^\uvec{p}p^​ is Aligned With the Node Line

By definition, the p^\uvec{p}p^​ vector points towards periapsis. Therefore, it is also aligned with the eccentricity vector. If we rotate the frame around the w^\uvec{w}w^ axis until p^\uvec{p}p^​ is aligned with the node line, this will align e\vector{e}e with N\vector{N}N. This rotation is the negative of the argument of periapsis, ω\omegaω.

Step 2.2—Rotate Until w^\uvec{w}w^ is Aligned With the ZZZ Axis

At this point, the node line and the eccentricity are aligned. Rotating around the node line changes the inclination of the orbit. When w^\uvec{w}w^ is aligned with the ZZZ axis, then the inclination, iii, has been accounted for.

Step 2.3—Rotate Until p^\uvec{p}p^​ is Aligned With the XXX Axis

The last step is to account for the right ascension of the ascending node. Since p^\uvec{p}p^​ is now aligned with the node line, we can rotate around the ZZZ axis to turn the orbital plane until it aligns with the XXX axis. This is the negative of the right ascension of the ascending node.

These three angles (ω\omegaω, iii, and Ω\OmegaΩ) are called Euler angles. Transformations based on the Euler angles are well known and can be calculated in many ways.

Python
Matlab
from scipy.spatial.transform import Rotation

R = Rotation.from_euler("ZXZ", [-omega, -i, -Omega])
r_rot = r_w @ R.as_matrix()
v_rot = v_w @ R.as_matrix()

In Python, the SciPy library includes a class to automatically compute the rotation matrix. The class takes the three angles and the axes about which the rotations should be done. In this case, our rotations are around the w^\uvec{w}w^ axis (the zzz axis of the perifocal frame), the xxx axis that is present after the first rotation, and finally, the zzz axis which is present after the second rotation.

Notice that the rotation is right-handed by default, positive clockwise. Since we are reversing the rotations, the angles all have to be negative.

To actually perform the rotation, we need to multiply the position and velocity vectors in the perifocal frame by the rotation matrix. The @ symbol in Python performs matrix multiplication, instead of scalar multiplication.

orbital_elements_and_the_state_vector.m
R1 = [cos(-omega) -sin(-omega) 0; sin(-omega) cos(-omega) 0; 0 0 1];
R2 = [1 0 0; 0 cos(-i) -sin(-i); 0 sin(-i) cos(-i)];
R3 = [cos(-Omega) -sin(-Omega) 0; sin(-Omega) cos(-Omega) 0; 0 0 1];
r_rot = r_w * R1 * R2 * R3;
v_rot = v_w * R1 * R2 * R3;

In Matlab, there is no built-in way to compute rotation matrices. Instead, the easiest step is to compose the rotation matrices for each direction and multiply the position and velocity vectors by the matrices.

The order that the multiplication occurs is important! This is because the rotation has to occur first around the w^\uvec{w}w^ axis, then about the new xxx axis generated by the first rotation, and finally around the new zzz axis created by the second rotation. If the rotations are specified in a different order, you will not get the right result.

In addition, notice that the angles must be specified as negative, since we are reversing the rotation from the perifocal frame to the inertial frame.

In the end, we find r=\vector{r} =r= 1000 I^\uvec{I}I^ + 5000 J^\uvec{J}J^ + 7000 K^\uvec{K}K^ km and v=\vector{v} =v= 3 I^\uvec{I}I^ + 4 J^\uvec{J}J^ + 5 K^\uvec{K}K^ km/s. This is exactly the same as the initial condition, showing that we did the conversion correctly.

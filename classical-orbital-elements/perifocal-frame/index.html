Perifocal Frame

In this section, we define the perifocal reference frame, a convenient reference frame for describing the planar orbits that we’ve been discussing. The perifocal frame is a Cartesian reference centered at the occupied focus of the orbit, the location where m1m_1m1​ exists. Since all the orbits we’ve looked at so far are planar, the xωyω\pf{x}\pf{y}xω​yω​ plane of the perifocal frame lies in the same plane as the orbit. This means that the zω\pf{z}zω​ direction is pointing in the same direction as the angular momentum.

The unit vectors that define this coordinate system are:

  1. 𝒑^\uvec{p}p^​ pointing along the xω\pf{x}xω​ axis

  2. 𝒒^\uvec{q}q^​ pointing along the yω\pf{y}yω​ axis

  3. 𝒘^\uvec{w}w^ pointing along the zω\pf{z}zω​ axis

As shown in Fig. 42, 𝒑^\uvec{p}p^​ points along the apse line to the right of the focus, towards periapsis. 𝒒^\uvec{q}q^​ points 90° true anomaly from 𝒑^\uvec{p}p^​. Finally, 𝒘^\uvec{w}w^ points in the same direction as the angular momentum, and can be defined by:

Interplanetary Phasing Example: Neptune–Venus Hohmann Transfer

Continuing the example from the previous section, we can determine the required phase angles for the Neptune–Venus Hohmann transfer and the total time taken for the transfer and the waiting period.

First, we compute the mean motion of Neptune and Venus.

import math as m
mu = 1.32712E11  # km**3/s**2

T_i = 60910.25  # days
T_f = 224.70  # days
n_i = 2 * m.pi / (T_i * 86_400)  # s
n_f = 2 * m.pi / (T_f * 86_400)  # s

The mean motion of Neptune is ni=n_i =ni​= 1.19e-09 rad/s and of Venus is nf=n_f =nf​= 3.24e-07 rad/s. For a Hohmann transfer, Γ=π\Gamma = \piΓ=π and the transfer time is found from Eq. 334. Then, we can find the initial phase angle required.

r_i = 4.53239E9  # km
r_f = 1.08209E8  # km
a_t = (r_i + r_f) / 2  # km
t_12 = m.pi / m.sqrt(mu) * a_t**(3/2)  # s

gamma_1 = (m.pi - n_f * t_12) % (2 * m.pi)

Note that we use the modulus (%) operator to bring the phase angle into the range of 0-2𝜋. The initial phase angle is γ1=\gamma_1 =γ1​= 307.04°. Although this is the initial phase angle, Venus actually completes approximately 53 orbits of the Sun while waiting for the spacecraft to arrive from Neptune. We can compute the phase angle at arrival similarly.

gamma_2 = (m.pi - n_i * t_12) % (2 * m.pi)

The phase angle at arrival is γ2=\gamma_2 =γ2​= 114.07°. These angles are shown in Fig. 86.

Using the final phase angle, we can compute the waiting time at Venus before a return Hohmann transfer is possible. Since nf>nin_f > n_inf​>ni​, we choose the positive version of Eq. 386.

t_wait = []
for N in (0, 1, 2, 3):
    t = (-2 * gamma_2 + 2 * m.pi * N) / (n_f - n_i)
    t_wait.append(t)
    if t > 0 and t_wait[N - 1] < 0:
      t_total = (2 * t_12 + t) / (525_600 * 60)

The wait times are shown in Table 7. The total mission time, including the wait time, is 61.35 years.

T_syn = T_i * T_f / abs(T_i - T_f)  # days
T_syn /= 365.25

Clearly, the total mission time is dominated by the transfer time. This is because the synodic period of Venus relative to Neptune is quite small, at only 0.62 Earth years. Since Venus whips around the Sun, relative to Neptune, the same phase angle occurs relatively often.
